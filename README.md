# Informe · @puch_realtor

Vitrina web interactiva del informe cuantitativo de 12 semanas (13 jul – 4 oct 2026) de Sergio Puch.
React + Vite + TypeScript + Tailwind + Recharts + Framer Motion. Diseño Matiz.

```bash
npm install     # una sola vez
npm run dev     # http://localhost:5173
npm run build   # genera /dist
```

Los datos viven en `src/data/report.ts`; las fotos en `public/img/`.
